# 定位

- 开箱即用的基础设施 + 明确的工程规范约束
- 目的是解决使用 fastapi 前要解决的基本问题
- 打造专为 AI 辅助编程、零配置的 FastAPI 脚手架
- 为了省去搭建数据库连通性、写鉴权、搞目录结构的折磨
- 开箱即用，用户只需要用自然语言跟 AI 提需求，例如：“在这个基础上，给我加个用户订单模块“
- AI 能够顺着基础设置完成功能，不用担心配置、环境上的错误，只需要专注于业务逻辑和功能上的实现
- 解决问题？
    - 如何连数据库：预装了全套的异步 MySQL + SQLModel
    - 事务怎么管：自动提交和回滚
    - 权限怎么做：JWT 和 Argon2 密码哈希方案
    - 多环境配置：Pydantic Settings 和 .env 方案
